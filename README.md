# FinPilot AI

AI-Powered Personal Finance & Financial Wellness Platform.

**Track. Analyze. Save. Grow.**

## Project

FinPilot AI helps users:

- Track income and expenses
- Manage budgets
- Set financial goals
- Analyze spending patterns
- Receive AI-powered financial insights
- Scan receipts using OCR
- Monitor financial health
